Data Flow

1

User opens app

index.html loads. React hydrates. localStorage checked for existing draft under key brand-brief-questionnaire-draft. If found, BrandBrief state is restored.

2

7-step wizard

User fills form fields. onChange updates nested BrandBrief state. After each change, full state is serialized to localStorage. Step navigation requires passing per-step validation.

3

Summary Page

All collected data rendered for review. User can jump back to any step to edit. Can also download brief locally as JSON or TXT without submitting.

4

Submit → POST /api/send-brief

BrandBrief JSON sent in request body. No auth. No CSRF protection. Recipient is hardcoded server-side.

5

Serverless function processes

Validates env vars → creates nodemailer transporter → builds .json + .txt attachments → sends via SMTP. Returns 200 on success.

6

Success / Error feedback

Client shows success message. No state reset — user must manually clear or navigate away. localStorage draft persists.

Risks & Weak Points

⚠️

App.tsx is a 1665-line monolith

All types, components, business logic, and state live in one file. Adding features is risky — no separation of concerns, hard to test, hard to navigate.

⚠️

Hardcoded recipient email in api/send-brief.ts

The email destination (v.demidov@urc.org.ua) is hardcoded. Changing it requires a code deploy. Should be an env var.

⚠️

No API authentication or rate limiting

/api/send-brief accepts any POST request. No auth, no CSRF token, no rate limiting. Anyone can spam the SMTP service.

⚠️

Uploaded files stored as base64 in state/localStorage

Visual reference images accumulate in localStorage as base64 strings. No size limit. Not sent via email — silently lost on submission. May hit localStorage quota (~5MB).

⚠️

No localStorage schema versioning

If BrandBrief type changes between deploys, stale drafts from localStorage will silently produce incorrect state. No migration or version check.

⚠️

No test coverage

Zero tests. No test framework installed. Validation logic, state transitions, and email function are untested.

ℹ️

Unused assets in src/assets/

react.svg and vite.svg are Vite scaffolding leftovers — not used in the application.
